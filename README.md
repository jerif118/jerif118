## 🚀 Proyectos destacados

### [OpenBreach](https://github.com/jerif118/OpenBreach) 🛡️

Proyecto desarrollado en el contexto de una **hackathon**, enfocado en validación defensiva y autorizada de seguridad para sistemas web públicos.

OpenBreach plantea un workflow donde se recopila evidencia pública mediante reconocimiento pasivo, se generan hipótesis de vulnerabilidad y cualquier validación de bajo impacto requiere previamente **aprobación humana**.

El proyecto prioriza:

- Reconocimiento pasivo
- Definición explícita del alcance autorizado
- Generación de hipótesis a partir de evidencia
- Approval gates
- Validaciones controladas
- Evidencia trazable
- Clasificación de riesgos
- Reportes técnicos y de remediación

**Stack y tecnologías:**

`TypeScript` · `React` · `TanStack Start` · `Node.js` · `Convex` · `Clerk` · `Mastra` · `TanStack AI` · `Zod`

El proyecto está diseñado con una arquitectura orientada a workflows y agentes, manteniendo controles de seguridad para evitar acciones fuera del alcance autorizado.

---

### [Pipeline_Derma](https://github.com/jerif118/Pipeline_Derma)

Pipeline experimental para clasificación de lesiones cutáneas utilizando imágenes reales y sintéticas.

El proyecto incluye preparación de datos, entrenamiento y evaluación de modelos de **Computer Vision**, así como comparación de diferentes escenarios experimentales.

---

### Clasificación de lesiones cutáneas con DINOv2 + StyleGAN2

Investigación enfocada en estudiar el impacto del balanceo sintético mediante **StyleGAN2** sobre un clasificador basado en **DINOv2** para lesiones cutáneas del dataset BCN20000.

Tecnologías utilizadas:

`Python` · `PyTorch` · `DINOv2` · `StyleGAN2` · `Pandas` · `NumPy`

Métricas utilizadas:

- Accuracy
- Balanced Accuracy
- F1 Score
- AUC
